# 简单业务模拟人

[通用参与者](../../agents/simple-business-user.agent.md) 根据提供的 Markdown 知识回答被测角色的问题。
真实知识存放在外部配置目录；[合成示例](../../examples/knowledge.md)只用于说明结构。

- 输入：知识文档、最新问题及必要的公开对话历史。
- 输出：自然语言回答，不使用结构化 Oracle 的事实 ID。
- 只回答已问到且有依据的内容，不主动展开隐藏规则、不虚构未决事项。
- 模拟参与者不是自然人审批人，回答不能变成需求/设计批准。

手工试用时在独立聊天提供知识全文，而不是只给工具禁用的参与者一个文件路径。
转发回答前人工审查；不要将私有知识加入被测 PM 的上下文。
自动运行使用[三层入口](../../README.md)，主线 Req 只向 PM 提供 `## 初始需求`。

知识有新批准时更新外部静态输入并开启新运行，不改过去的冻结文本。
Oracle/JSON 知识工具属于不同协议，不能只替换 Agent 定义就互换。
